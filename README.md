
# Travel Booking System

A web-based travel booking application that helps users explore Indonesian destinations and manage travel bookings.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap 5
- Leaflet.js

## Main Features

- Explore Indonesian tourist destinations
- Interactive map
- Travel booking form
- Payment management
- Booking confirmation

## DevOps Implementation

This project will be enhanced using Docker for application containerization and GitHub Actions for CI/CD automation.
